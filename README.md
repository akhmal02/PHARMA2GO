# PHARMS2GO
The project titled PHARMA2GO focuses on developing an online platform to implement an e-commerce system that allows users to conveniently purchase over-the-counter (OTC) medical products through a website or mobile application. In the modern digital era, convenience and accessibility have become key aspects of consumer behavior. Despite this, many individuals still rely on physically visiting pharmacies to obtain basic medical supplies such as pain relievers, supplements and first-aid products. PHARMA2GO aims to digitalize this process by providing a centralized and user-friendly solution that enables customers to browse, check product availability, compare prices and purchase OTC medical items from verified pharmacies without the need to visit the store.

This project involved as  below:
1. Code segment (Java, Servlet, HTML/CSS/JavaScript, JSP, JDBC, JavaBean)
2. Database (MySQL)
